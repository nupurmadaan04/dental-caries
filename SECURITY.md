# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.4   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within this project, please responsibly report it by creating a private security advisory or contacting the maintainers directly through GitHub.

Please do not disclose security vulnerabilities in public issue trackers. We will review and patch verified security issues promptly.
